## Описание проекта

Многостраничный HTML/CSS-сайт вымышленного интернет-магазина механических клавиатур. Без CSS-фреймворков, JavaScript используется только для открытия и закрытия модального окна.

## Ссылка на опубликованный проект

GitHub Pages: https://assgeier.github.io/kr1-html-css-shop/

## Структура проекта

```
kr1-html-css-shop/
```

## Используемые технологии

HTML5, CSS3 (переменные, Flexbox, Grid, position), БЭМ, минимальный JavaScript (`<dialog>`), Git, GitHub Pages.

## Как посмотреть проект

1. Открыть ссылку GitHub Pages выше.
2. Либо скачать репозиторий и открыть `index.html` в браузере.

## Обязательные страницы

- index.html: hero-блок, преимущества, популярные товары, отзывы, FAQ, контакты.
- catalog.html: категории, статический блок фильтров, сетка карточек, модальное окно.
- product.html: изображение, описание, цена, таблица характеристик, кнопка заявки.
- order.html: форма заявки с валидацией.
- contacts.html: адрес, телефон, e-mail, время работы, ссылка на форму.

## Самостоятельные доработки

- Собственная визуальная концепция и цветовая схема на CSS-переменных.
- Бейджи «Хит», «Новинка», «Скидка» и БЭМ-модификаторы карточек (`product-card--hit` и др.).
- Хлебные крошки на внутренних страницах.
- Блоки отзывов и FAQ на `<details>`.
- Вторая таблица: сравнение комплектаций.
- Sticky-фильтры каталога и sticky-блок на странице товара.
- Кнопка «Наверх» (`position: fixed`).
- Модальное окно на `<dialog>` с формой (`method="dialog"`).
- Доступность: skip-link, видимый `:focus-visible`, подписи полей, `aria-current`, состояние `:user-invalid`.
